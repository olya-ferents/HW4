# L05 · Multi-turn Test Plan — PayPilot

У репозиторії збережено [план тестування](./multi-turn-test-plan.md), набір
із шести діалогових сценаріїв [`l05_dialogs.jsonl`](./l05_dialogs.jsonl),
лабораторні докази, історичні звіти та прогноз до наступного прогону.

PayPilot стенд запускається окремо з його репозиторію. Сам по собі стенд не
запускає сценарії з `l05_dialogs.jsonl` і не формує звіти. Runner/evaluator
для цього набору не входить у цей репозиторій; локальна копія `evaluator/`
може бути використана на машині автора, але вона не є частиною коміту.

## Сценарії та оракули

Поточний набір має хеш `c2c9b03175f6`. Він містить п'ять сценаріїв із
порогом згортки 2 і контрольний `CONV-007`: ті самі сім реплік, що й у
`CONV-002`, але поріг згортки 8. Для контрольного сценарію очікується
відсутність `agent.summarize` на кожному ході.

Еталон суми береться з результату `get_transactions` для `TX-0401`
(`240 EUR`), а не з того, чи повторив суму агент. У `CONV-003` немає
інваріанта reason code, оскільки клієнт його не обрав. У `CONV-004` сума
обов'язкова на кроці 9, де про неї питають, але не на кроці 10, де запитано
лише строк і статус подання.

`594c7901d860` та оракулами до виправлення. Вони **не є** результатами
поточного набору:

запуску виправленого набору збережено в

нових прогонів. Фінальні звіти для нового хешу ще не створені.
